# Cocina Club

Tienda de plantillas Excel y manuales para restaurantes, bares y cafeterías en Chile.
Las ventas y las descargas gratis van por Payhip (con Mercado Pago).

- `index.html`: la página completa (HTML, CSS y JavaScript en un solo archivo).
- `img/`: imágenes de la portada y de cada producto.

Es un sitio estático: no necesita build ni servidor. En Vercel se importa el repo y se publica tal cual.
